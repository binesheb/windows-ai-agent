# Surface Book 3 Manual Inspection

- [ ] No battery swelling or display lifting
- [ ] No cracked display
- [ ] Black/white/red/green/blue pixel test
- [ ] Touch works across the whole panel; no ghost touches
- [ ] Every keyboard key
- [ ] Trackpad click and gestures
- [ ] Front/rear camera
- [ ] Windows Hello
- [ ] Speakers and microphones
- [ ] Wi-Fi and Bluetooth
- [ ] USB-A x2
- [ ] USB-C data and charging
- [ ] SD card
- [ ] 3.5 mm audio
- [ ] Surface Connect base charging
- [ ] Surface Connect tablet charging
- [ ] Detach and reattach twice
- [ ] GTX 1660 Ti returns after reattachment
- [ ] Charger remains stable while moving hinge
- [ ] Serial matches seller paperwork
- [ ] No BIOS password or organization/Autopilot lock
- [ ] Seller permits full testing/return

## Walk away for

Battery swelling, display lifting, cracked/touch-defective panel, missing GPU, detach failure, intermittent charging, SSD failure, repeated WHEA/storage/display errors, or unexplained shutdowns.
